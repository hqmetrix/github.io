eCQM Submission Guide: from EHR data to a clean upload

Seven steps that take electronic clinical quality measure data from source systems to a file CMS accepts.

Blog · Last checked November 17, 2026

← Blog

1. Lock the specification

Use the measure versions CMS names for the performance year. The eCQI Resource Center is the source for specifications, value sets and test data. A practice running last year's version will produce numbers that do not match.

2. Inventory the sources

List every practice, its EHR and release, and what each can export. Note which can produce a quality report file and which can only export clinical data.

3. Extract and standardize

  • Pull patients, encounters, diagnoses, results, procedures, medications and immunizations for the measurement period.
  • Map local codes to the value sets the measure uses.
  • Match patients across practices so each person is counted once.

4. Calculate

Run the measure logic once, consistently, for every patient. Record the initial population, denominator, exclusions, exceptions and numerator for each measure.

5. Validate

  • Compare your result with each EHR's own report on a sample and explain differences.
  • Run QRDA files through CMS's pre-submission tools, including Cypress for measure logic and the QRDA III converter for QPP JSON.
  • Check completeness: the patients you included against the patients who were eligible.

6. Generate the file

QRDA III is an aggregate report for a set of patients and is the format clinicians submit to CMS. ACOs may also upload QPP JSON. Confirm the program name and the certified technology identifier before you build files.

7. Submit and keep evidence

Upload during the window, review what the QPP site shows, and save the files, the logs and the validation notes. Data cannot be corrected after the window closes.

TipDo steps 1 to 5 monthly, not once. The final submission is then a repeat of something you already do.

At a glance

  • Start with the measure version and the performance period
  • Validate before you file, not after
  • QRDA III is the clinician and ACO submission format
  • Keep the evidence for every number
