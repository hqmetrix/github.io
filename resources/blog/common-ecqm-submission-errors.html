Common eCQM Submission Errors and how to avoid them

The mistakes that get files rejected or scores wrong, grouped by where they happen.

Blog · Last checked November 17, 2026

File and format errors

ErrorWhy it happensFix
File not recognized as a QRDA III documentBuilt to an old implementation guide or malformed XMLBuild to the guide for the performance year and validate before upload
Invalid measure identifierMeasure GUID or ID from the wrong year or versionUse the identifiers CMS publishes for the year
Measure under the wrong submission methodeCQM listed under registry or CQM under electronic health recordKeep each measure under the method that matches its collection type
Wrong programFile not marked for APP PlusSet the program name before you upload
Missing or wrong certified technology IDNot generated for the products usedCreate the ID from the certified products you used

CMS's own upload troubleshooting guide is the best list of current error messages. Use the year-specific edition.

Data errors the upload will not catch

  • Duplicate patients across practices inflate denominators.
  • Unmapped codes drop patients from numerators or exclusions.
  • Exclusions recorded as free text never reach the measure logic.
  • Practices on different measure versions are combined.
  • A missing practice file lowers completeness below 75%.
  • Counts are summed incorrectly when combining files, for example summing rates instead of counts.

Process errors

  • Waiting until March to run the first full validation.
  • Having one person who knows how to build the file.
  • No saved evidence of what was submitted and why.

A short prevention list

  1. Run CMS's pre-submission tools on every file you will submit.
  2. Compare your results with each source system's.
  3. Track completeness monthly.
  4. Upload a test file in early January.
  5. Log every correction and its cause.

At a glance

  • File errors reject the upload
  • Data errors accept the upload and give the wrong score
  • Test with CMS tools before the window
  • Keep a log of every fix
