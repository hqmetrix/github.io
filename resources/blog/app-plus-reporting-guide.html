Mixing collection types

An ACO can report measures through different collection types and can report the same measure through more than one. When it does, CMS counts the collection type with the most achievement points for that measure and ignores the rest. That makes it worth submitting more than one route only when you can support both well.

How data reaches CMS

  • An APM Entity user uploads a QPP JSON file or a QRDA III file on the QPP site.
  • A third-party intermediary can submit for you; you sign in during the window to review what was received.
  • Set the program to APP Plus. A file submitted under the wrong program can be scored under a different pathway.
  • You will not see claims-based measures or CAHPS during the submission period.
  • Data cannot be updated or corrected after the submission period closes.

A practical order of work

  1. Choose routesPick a collection type per measure from data quality and benchmark position, not habit.
  2. Build the populationInclude every eligible patient across practices, once.
  3. ValidateCompare your calculation with each source system's own result.
  4. Create the fileGenerate QRDA III or QPP JSON for each route you will submit.
  5. Test, then submitRun the file through CMS's validation tools, upload early, and review the QPP dashboard.

The 2025 submission guide is the most detailed source on screens and file handling. Use the 2026 edition when CMS posts it, since screens and requirements can change.

At a glance

  • Three collection types in 2026, a fourth from 2027
  • Only the best-scoring collection type counts per measure
  • Upload a QPP JSON or QRDA III file, or use a third party
  • Set the program name to APP Plus
