Upload QRDA I files and see the same HbA1c and blood pressure measures calculated, patient by patient.

Demonstration only. Everything runs in your browser and nothing is uploaded. Please do not use real patient data on this public page. The calculation uses a representative subset of the code lists, not the full VSAC value sets, so it illustrates the logic and is not a certified eCQM engine. Measure logic follows the 2026 performance period specifications for CMS122v14 and CMS165v14 on eCQI Resource Center.
